# ZarishHealth website

This repository contains the public GitHub Pages homepage for [ZarishHealth](https://zarishhealth.github.io/), an offline-first, self-hosted health information system for low-resource and intermittently connected environments.

## Files

- `index.html` — accessible, responsive homepage
- `styles.css` — site styling using the ZarishHealth brand system
- `.nojekyll` — keeps GitHub Pages from processing files through Jekyll

## Brand assets

The homepage uses the approved ZarishHealth logo, icon, banner, favicon and social preview assets from [zarishhealth/.github/profile/assets](https://github.com/zarishhealth/.github/tree/main/profile/assets). They are referenced from the organization’s raw GitHub asset URLs so the same approved files can be maintained centrally without duplicating binary files.

## Publish with GitHub Pages

1. Open the repository Settings tab.
2. Select Pages in the left sidebar.
3. Under Build and deployment, select Deploy from a branch.
4. Choose the main branch and the / (root) folder.
5. Select Save.
6. Wait for deployment, then open https://zarishhealth.github.io/

## Content and safety

The site describes the project as a prototype and does not claim that the software itself automatically provides HIPAA, GDPR, medical-device or other regulatory compliance. Do not place patient-identifiable information, credentials or secrets in this repository.
